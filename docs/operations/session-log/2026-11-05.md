## BookCraft: finished L1/L2 and registered it in Democraft

**Agent:** opencode (continued from an Antigravity scaffold)

### bookcraft (D:\Dev\repos\bookcraft)

- The Antigravity scaffold declared `library`, `convert` and `ingest` modules but did not
  contain them, and `bookcraft-mcp` had no `src/`. It did not compile.
- Implemented L1 `bookcraft-core`: read-only Calibre reader (`SQLITE_OPEN_READ_ONLY`),
  `ebook-convert` discovery and conversion with collision-free output, deterministic
  HTML-to-Markdown ingest with a 16 MiB cap, and the shared `dispatch`.
- Implemented L2 `bookcraft-cli`: 10 verbs (`status/list/search/info/grep/stats/convert/
  ingest/tools/mcp`), `--json` everywhere, hand-rolled MCP 2024-11-05 stdio with 8 tools.
- Added 24 tests, justfile, README, INSTALL, AGENTS, CHANGELOG, docs/PRD, docs/TOOLS,
  start.ps1/bat, HANDOVER, Cargo.lock.

Two real bugs found by the live run and fixed with regression tests: Calibre's `data.name`
omits the file extension (format files were reported missing), and `strip_html_tags` put a
space before closing punctuation.

Verification: clippy `-D warnings` clean; 24 tests pass; `cargo fmt --check` clean; MCP
stdio probe 5/5 JSON with 8 tools; live read-only run on a 10,346-book library (search,
info, full-text grep, EPUB -> TXT in 3.3 s, `metadata.db` mtime unchanged); `--root`
confinement rejected an out-of-root library.

### democraft-mcp (D:\Dev\repos\democraft-mcp)

- Registered `book` / `BookCraft` in `crafts.py` with HERO metadata (clone_of, description,
  3 gaps) and 4 demos; `capability-map` is appended by the registry as for every app.
- Added real recipes in `recipes.py`: `search-and-info`, `convert-roundtrip`,
  `fulltext-find`, `readly-ingest-sim`. Each builds a deterministic Calibre-shaped fixture
  (metadata.db + minimal EPUB 2 + full-text-search.db) in its own run directory, so no real
  library and no DRM book is touched. Conversion reports `down` and skips honestly when
  Calibre is absent.
- Added the `book` hue/icon to `webapp/src/lib/appMeta.ts`, a `test_book_recipes` test, and
  a CHANGELOG entry.

Verification: `ruff check .` and `ruff format --check .` clean; `bun run check` (tsc +
biome, 34 files) clean; full pytest suite 115 passed at 59.19% coverage (gate 55%).
