# Windows Utilities

Essential tools for system management, file operations, and automation.

## WizFile
**Category:** File Search
- **Description:** An ultra-fast file search utility that reads the Master File Table (MFT) directly from NTFS formatted drives.
- **Key Features:**
  - Instant search results.
  - Very low system resource usage.
  - Support for custom filters.
- **Links:**
  - 🌐 [Official Website](https://antibody-software.com/wizfile/)
  - 💬 [Subreddit (Generic)](https://www.reddit.com/r/software/)

## WizTree
**Category:** Disk Analyzer
- **Description:** The world's fastest disk space analyzer. It scans your hard drive and shows you which files and folders are using the most disk space.
- **Key Features:**
  - Visual treemap of disk usage.
  - MFT scanning for speed.
  - Easy file deletion and management.
- **Links:**
  - 🌐 [Official Website](https://diskanalyzer.com/)
  - 💬 [Subreddit (Generic)](https://www.reddit.com/r/software/)

## Hasleo Backup Suite
**Category:** Backup & Restore
- **Description:** A free Windows backup and restore software.
- **Key Features:**
  - System, disk, and partition backup.
  - Delta/Incremental backups.
  - WinPE bootable media creation.
- **Links:**
  - 🌐 [Official Website](https://www.easyuefi.com/backup-software/backup-suite-free.html)
  - 💬 [Subreddit (Generic)](https://www.reddit.com/r/Backup/)

## AutoHotkey
**Category:** Automation
- **Description:** A powerful, open-source scripting language for Windows desktop automation.
- **Key Features:**
  - Remap keys and buttons.
  - Automate repetitive tasks.
  - Create custom GUI applications.
  - **Version:** v2.0+ recommended for new scripts.
- **Links:**
  - 🌐 [Official Website](https://www.autohotkey.com/)
  - 💬 [r/AutoHotkey](https://www.reddit.com/r/AutoHotkey/)
