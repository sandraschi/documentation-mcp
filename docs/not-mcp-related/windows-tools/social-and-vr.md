# Social & VR

Platforms for virtual interaction and immersive experiences.

## VRChat
**Category:** Social VR
- **Description:** An online virtual world platform. Created allows users to interact with others as 3D character models.
- **Key Features:**
  - Community-created worlds and avatars (UGC).
  - Unity SDK integration.
  - Full-body tracking support.
  - PC and standalone VR headset support.
