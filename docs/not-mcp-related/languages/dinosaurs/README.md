# The Dinosaurs: Foundations of Computing

> [!NOTE]
> **"Old Gods"**: These languages are the bedrock upon which all modern computing stands. They are not dead; they are simply deep underground, supporting the weight of the world.

In the **Antigravity Fleet**, we treat these languages with the respect due to ancient, powerful tools. We do not use them for new web services, but we maintain proficiency in them because:
1.  **Performance**: Nothing beats handwritten Assembly or optimized Fortran.
2.  **Legacy**: The world's banking system runs on COBOL. The world's physics simulations run on Fortran.
3.  **Kernel**: The Linux kernel and embedded systems run on C.

## 🦖 The Four Pillars

| Language | Role | Implementation |
| :--- | :--- | :--- |
| **[Assembler](./assembler)** | The Metal | Bootloaders, SIMD Optimization, Reverse Engineering |
| **[Fortran](./fortran)** | The Calculator | Physics Simulations, Linear Algebra (BLAS/LAPACK) |
| **[COBOL](./cobol)** | The Ledger | Banking Systems, Insurance Backends |
| **[C](./c)** | The Lingua Franca | Operating Systems, Embedded Firmware, Python Interpreter |

## 📅 Chronology of the Titans

* **1949**: Assembly Language (EDSAC)
* **1957**: Fortran (IBM)
* **1959**: COBOL (CODASYL)
* **1972**: C (Bell Labs)

---

## 🛡️ Usage in SOTA 2026

While we default to **Rust** for new systems-level code, we interact with these languages daily:
*   **C**: Via `bindgen` in Rust or `cffi` in Python.
*   **Fortran**: Via `f2py` for high-performance math.
*   **Assembler**: When debugging crash dumps or optimizing inner loops.
*   **COBOL**: Rarely, but essential for interfacing with legacy financial APIs.
