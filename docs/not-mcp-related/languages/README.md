# Languages Documentation Hub (SOTA 2026)

**Centralized Knowledge for Multi-Language Development**

This hub provides a tiered approach to language mastery within the Sandra AI system, optimized for February 2026 standards.

---

## 📁 Tiered Structure

Every language in this directory follows a strict three-tier structural pattern:

- **`docs/`**: Official project documentation, architecture patterns, and standards.
- **`learning/`**: Tutorials, internal training materials, and skill acquisition paths.
- **`reference/`**: API documentation, cheat sheets, and technical specifics.
- **`bibliography/`**: Curated resources, books, and deep-dive technical material.

---

## 📚 External Resources & Bibliography

**The Sandra Library (Calibre)**

Our extensive collection of IT books and scientific papers is managed via **Calibre**.

- **Access**: Use the `calibre-mcp` server for semantic search and retrieval or access the webapp directly for browsing.
- **Integration**: Each language contains a `bibliography/` folder with links/references to SOTA books found in the Calibre library.
