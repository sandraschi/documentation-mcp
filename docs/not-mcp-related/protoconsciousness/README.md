## The Core Shift

Historically, LLMs have been stateless oracles. They wake up, process a prompt, return a sequence of tokens, and die. 

**Protoconsciousness requires three new pillars:**
1. **Unbroken Temporal Reality:** The model must process a continuous, streaming flow of sensory data (usually video/audio) without dropping frames due to quadratic context costs.
2. **Anticipatory Horizon:** The model must maintain a "World Model" that predicts the *next* series of frames or events, acting proactively rather than merely reacting to explicit prompts.
3. **Internal State Mutation:** The model (or local cluster, like the robofang *Council of Dozens*) must maintain a persistent, internally mutating "stream of consciousness" that evaluates its own outputs over time.

This documentation serves as the blueprint for realizing these capabilities within our MCP ecosystem and robotic hardware (Unitree/Moorebot integrations).
