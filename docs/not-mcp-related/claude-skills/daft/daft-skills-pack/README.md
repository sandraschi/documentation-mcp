# Daft Skills Pack - Complete Critical Thinking Collection

**12 educational skills that teach critical thinking by exposing nonsense**

## ⚠️ Educational Purpose ONLY

These skills EXPOSE tricks to teach critical thinking - NOT to promote daft ideas!

Each skill teaches:
- How the trick/fallacy/pseudoscience works
- Why it fails logical/scientific testing
- What cognitive biases enable belief
- How to recognize and defend against manipulation

## The Complete Collection (12 Skills)

### Pseudoscience Debunkers (5)
1. **seance-mistress** - Cold reading, hot reading, Barnum effect, fishing
2. **flat-earth-expert** - Physics debunking, evidence standards, why claims fail
3. **homeopathy-researcher** - Dilution math (10^60!), Avogadro's number, placebo
4. **reborn-queen-of-sheba** - Reincarnation claims, false memories, burden of proof
5. **astrology-analyst** - Barnum effect, twin problem, precession, no mechanism

### Critical Thinking Tools (4)
6. **derrida-explainer** - Academic obfuscation, Sokal Hoax, clarity vs complexity
7. **cultural-appropriation-handwringer** - Genuine vs performative, centering affected voices
8. **sneaky-debater** - Logical fallacies (Gish Gallop, Motte & Bailey, Kafka Trap, etc.)
9. **racist-with-jewish-friends** - Deflection tactics, implicit bias, systemic issues

### Ideology Critiques (3)
10. **blockchain-pollyanna** - Tech hype, solutions looking for problems, trade-offs
11. **ai-doomster** - Sci-fi panic vs real risks, unfalsifiable fears, evidence-based thinking
12. **accelerationist** - Revolutionary romanticism, controlled collapse myth, real harm
