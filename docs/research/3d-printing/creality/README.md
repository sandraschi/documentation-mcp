## Quick verdicts (2026-10-18)

* SparkX i8 at $309 Early Bird: good value for PLA/PETG 4-color toys, NOT an open-stack printer, NOT for TPU / ABS / ASA / multi-material.
* M1+R1 at $899 VIP / $1199 Early Bird / $1699 MSRP: only pays off if you generate kg of clean sorted scrap monthly AND enjoy tinkering. For casual saving-money use case: skip, buy spools.
* Open stack: half-open. GPL Klipper forks published (delayed, partial blobs), CrealityOS/cloud/QuarTeks closed. More open than Bambu, far from Prusa/Voron/Sovol SV08.
