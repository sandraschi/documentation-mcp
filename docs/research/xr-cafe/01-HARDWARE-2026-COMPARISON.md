# 01 — Hardware Comparison 2026: Cafe Work Glasses

**Date:** 2026-09-26. Prices USD MSRP, EUR ~ +10-20% + VAT. Check manufacturer sites.

## 1. What counts

Birdbath micro-OLED, USB-C DP-Alt, 3.5mm-ish audio via arms, IMU for 3DoF on some. No compute, no cameras (except Beast/Luma Ultra front cam for future 6DoF). If it needs a battery + Snapdragon + cameras, it's a different category (Vision Pro / Quest / Galaxy XR) — out of scope for cafe tables.

Optics in one line: micro-OLED -> birdbath combiner -> your eyes. Bigger FOV = bigger virtual screen but harder edge sharpness. Brighter nits = survives cafe windows. Electrochromic dimming = electronic sunglasses to boost contrast.

## 3. Detail notes (from ZDNET Mar 2026 + 400h YouTube shootouts)

* **FOV vs sharpness:** Beast 58deg feels cinematic but edges need perfect IPD/nose-pad fit. Luma Pro smaller effective sharp area but denser pixels in fovea — better for code. Don't chase FOV alone for work.
* **Brightness:** indoor cafe 700 nits + 3-level dimming (XREAL) is fine. Window seat / sun terrace needs 1200+ (Beast / RayNeo) or physical shade cover (all ship one, RayNeo 3s Pro magnetic shade extra useful).
* **3DoF quality:** XREAL X1 anchor stays put on fast head turns. Beast stable unless you bump frames (water-ripple). RayNeo app 3DoF drifts — turn it off for work, accept head-locked.
* **Myopia:** Viture dials win if you are -myopic and hate inserts. XREAL/RayNeo need prescription inserts.
* **Audio leak:** all leak at high volume. Cafe-safe: keep <50% or wear earbuds, use glasses speakers for calls only.
* **Heat:** X1 generates forehead warmth after 60-90min. Not dangerous, noticeable.
* **Patent/market noise:** Dec 2025 DE ban chatter VITURE vs XREAL, Counterpoint H1 2025: XREAL+RayNeo >60% birdbath share. Buy from retailer with returns.

## 5. Buying advice for Vienna cafe

* **If one glass for work Dec 2026:** XREAL One Pro (or 1S if cheaper) for anchoring + ultrawide, else VITURE Luma Pro if you prioritize text + myopia dials. Try nose pads in store — fit = sharpness.
* **If budget:** RayNeo Air 3s Pro $299 — accept head-locked, buy shade.
* **Don't buy Beast at $549 until 1200p120 + 6DoF FW is public and reviewed.** Same for any "6DoF via future update" promise.
* **Cable:** right-angle USB-C 90-degree, 0.5m, DP-Alt rated, matched to your laptop port side. This matters more than specs in a tight cafe.
* **Try before Xmas:** order 2, keep 1. Text test: 10pt JetBrains Mono terminal + browser DevTools, 90min session, window-seat check.

## 6. What NOT to buy for this project

* Ray-Ban Meta / Even Realities / Halliday: no usable work display.
* Vision Pro / Quest 3 / Galaxy XR: great tech, cafe-social suicide + bulk + battery anxiety.
* Cheap no-name DP glasses with no returns: dead pixels + no firmware.
