Key Concepts

▶ Context Bomb
A short string that triggers safety guardrails in AI agents, planted in decoy resources or public content.
▶ Scout Model
A model with a different guardrail profile that reads content first and detects bombs by being immune to them.
▶ Sentinel Convention
Dotfiles (.ai-readiness, .nopublish) that signal intent to cooperative agents and terminate adversarial ones.
▶ Permission Manifest
Declaring filesystem/network/shell scope per MCP server — the missing permission model for the MCP ecosystem.
