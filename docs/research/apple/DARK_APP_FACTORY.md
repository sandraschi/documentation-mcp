# iOS Dark App Factory (Xcode 26.3)

> [!IMPORTANT]
> **Core Mandate**: The user has **ZERO** Swift knowledge and zero interest in learning the Apple infra stack.
> - All development, debugging, testing, and publishing is performed by **AI Orchestration**.
> - The human occupies the role of **Conductor of Intent (Vibearchitect)**.

## 1. The Zero-Swift Protocol

Building on the **Xcode 26.3 Revolution**, the Dark App Factory (DAF) for iOS utilizes a "High-Level Agentic Design" (HLAD) workflow:

1.  **Vibe Input**: User provides a terse `vibe.md` (e.g., "Build a Tapo camera monitor for the 9th District").
2.  **Intent Orchestration**: Xcode 26.3 "Vibecoding" specialists expand the vibe into a full functional spec.
3.  **Substrate generation**: The DAF Worker Council generates a **Capacitor/Vite** bridge.
4.  **Native Synthesis**: AI specialists manage all `SwiftUI` boilerplate, `Info.plist` configurations, and Entitlements autonomously.
5.  **Autonomous Judge**: The "Satisficer" runs `XCITEST` inside the internal Simulator, captures logs, and auto-fixes regressions.
6.  **Dark Publishing**: AI manages the `Fastlane` pipeline to push builds to TestFlight/App Store without manual form-filling.

## 3. Implementation Workflow

### Phase A: Vibe Enrichment
The **Foreman** specialist takes the raw idea and enriches it with the specific Apple API requirements (e.g., Background Tasks for Trash Sentinel).

### Phase B: Worker Council (iOS Flavor)
- **Sculptor**: Handles the Vite/React frontend.
- **Nervos**: Configures the iOS native bridge (Capacitor).
- **Maestro**: Orchestrates the local LLM for Xcode 26.3 Predictive Completion.

### Phase C: Automated XCITEST
The **Satisficer** executes the app in the Simulator. If the app fails to stand up (e.g., `Thread 1: signal SIGABRT`), the **Auditor** analyzes the log and re-triggers the Worker Council for a patch.

### Phase D: Hands-Off Publishing
AI prepares the screenshots (via `Rodney`), generates the meta descriptions, and pushes to App Store Connect via the `publishing` protocol.

---

## 4. Maintenance & Safety
- **Zero-Touch Regressions**: Any iOS update that breaks the factory is analyzed by the AI, and patches are applied globally to all 20 apps.
- **Audit Logs**: Every AI-driven change is logged in the `Showboat` report for human oversight.
