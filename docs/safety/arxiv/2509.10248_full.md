Title: Prompt Injection Attacks on LLM Generated Reviews of Scientific Publications
Author: Janis Keuper
Institution: Institute for Machine Learning and Analytics (IMLA), Offenburg University

Key Results:
- Simple prompt injections are highly effective, reaching up to 100% acceptance scores
- LLM reviews are generally biased toward acceptance (>95% in many models)
- Text-based PDF parsers (PyMuPDF, Mistral OCR) preserve hidden white-on-white text injections
- Image-based OCR ignores invisible prompts
- Models that follow instructions precisely are more vulnerable to manipulation

Structure:
1. Using LLMs to write Reviews: mostly forbidden - widely applied
2. Experimental Setup (Data, Document Parsing, Structured Output, Prompts, Models)
3. Results (Parsing Injections, Structured Output Validation, Effects of Prompt Injection)
4. Discussion

Models tested: GPT-5-mini, GPT-5-nano, Gemini-2.5-Pro, Gemini-2.5-flash, Gemini-2.5-flash-lite, Mistral, DeepSeek R1, LLAMA3.1, Qwen3
