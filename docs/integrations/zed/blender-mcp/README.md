# Blender MCP Zed Extension

This extension integrates the Blender MCP server with Zed IDE for AI-assisted 3D content creation.

## Features

- 3D modeling and animation control
- Material and texture management
- Scene composition and lighting
- AI-assisted creative workflows

## Installation

1. Clone this repository
2. Run the build script for your platform:
   - Windows: `./build.ps1`
   - macOS/Linux: `./build.sh`
3. In Zed IDE: Extensions → Install Dev Extension → Select this directory

## Requirements

- Rust toolchain with WASM target
- Blender MCP server installed
- Zed IDE

## Usage

Once installed, the Blender MCP context server will be available in Zed for 3D content creation workflows.
