# Unity3D: The Simulation & XR Hub

Unity3D is the central execution platform for the fleet's virtual operations. It acts as the primary "World" where robots are tested, XR experiences are authored, and social avatars are orchestrated.

## 🏛️ Role in the Sandra Ecosystem

- **Robotics Simulation**: The primary testing ground for **Unitree** and **Scout** robots before physical deployment.
- **XR Hub**: Authoring environment for social VR platforms (**VRChat**, **Resonite**).
- **Visual Feedback**: Real-time monitoring of agentic behaviors through the Unity Scene View.
