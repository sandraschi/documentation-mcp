# Notion: Distributed Project Management (SOTA 2026)

Notion is the primary platform for distributed project orchestration, structured databases, and collaborative planning in the **Sandra** ecosystem.

## 🏛️ Role in the Sandra Ecosystem

- **Project Tracking**: Using Notion's relational `data_source` primitives to track task status and dependencies.
- **Semantic Memory**: Serving as the primary corpus for the agentic RAG pipeline.
- **Resource Registry**: Maintaining a structured list of fleet hardware, licenses, and passwords.
- **Public Reporting**: Creating clean, web-accessible project status pages for external partners.
