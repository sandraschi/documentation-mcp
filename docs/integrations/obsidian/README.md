# Obsidian: Technical Knowledge & Vault Management

Obsidian is the primary "Second Brain" and local-first knowledge graph for the **Sandra** ecosystem. It is used to store high-density research, project documentation, and persistent memory.

## 🏛️ Role in the Sandra Ecosystem

- **Knowledge Graph**: Storing interconnected technical notes (`[[Zettelkasten]]`) and design documents.
- **Local-First Memory**: Providing a durable, markdown-based archive independent of cloud services.
- **Agentic Resource**: Serving as the primary corpus for the **Advanced Memory (ADN)** system.
