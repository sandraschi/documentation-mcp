# Notepad++: Lightweight Technical Text Editing

Notepad++ is the primary lightweight, multi-tabbed editor in the **Sandra** ecosystem, used for rapid log analysis, config file tweaking, and quick scratchpad operations on the Windows workstation.

## 🏛️ Role in the Sandra Ecosystem

- **Log Analysis**: Handling massive `.log` and `.txt` files with zero-lag scrolling.
- **Config Management**: editing `.env`, `.json`, and `.yaml` files outside of heavy IDEs.
- **Agentic Scratchpad**: A target for the AI to dump intermediate data or formatted reports for human review.
