# Notepad++: Technical Specifications

This document outlines the optimization and configuration of Notepad++ on the Sandra workstation.

## 💻 Environment

- **OS**: Windows 11 Pro.
- **Architecture**: x64.
- **Encoding**: UTF-8 (No BOM) is the system standard.

## ⚙️ Configuration & Plugins

- **Auto-Completion**: Enabled for all technical languages.
- **Mandatory Plugins**:
  - **NppExec**: For running external terminal commands directly from the editor.
  - **JSON Viewer**: For pretty-printing raw API responses.
  - **Compare**: For technical diffing of log files or config variants.
  - **NppFTP**: For secure remote editing of Linux-based robot configurations.

## 🎨 Theme Standards
- **Theme**: "Deep Black" or "Sandra-Modern" (Custom HSL-based).
- **Font**: "Cascadia Code" or "JetBrains Mono" with ligatures.
