# Entire.io Checkpoints CLI Integration

The Entire.io Checkpoints CLI provides an observability and audit layer for AI-assisted development. It links code changes directly to the AI agent's reasoning, intent, and context, capturing full sessions as versioned data within Git.

## Overview

- **Purpose**: Bridge the "provenance gap" by recording how AI agents contribute to codebases.
- **Mechanism**: Captures session transcripts, prompts, files touched, token usage, and tool calls.
- **Storage**: Append-only audit logs stored on a dedicated hidden Git branch (`entire/checkpoints/v1`).
- **Linking**: Links commits to agent reasoning via a unique Checkpoint ID.

## Core Features

- **Session Recording**: Automatically captures prompt-to-code transitions.
- **Auditability**: Searchable history of agent "why" for any code change.
- **Rewind/Rollback**: Ability to revert the repository to a known-good checkpoint if an agent fails.
- **Shared Memory**: Path toward a universal semantic reasoning layer for multi-agent coordination.

## Installation

```bash
# Install via npm
npm install -g @entire/checkpoints-cli
```

## CLI Commands

| Command | Description |
| :--- | :--- |
| `checkpoints enable` | Initialize Entire.io in the current repository. |
| `checkpoints disable` | Remove Entire.io hooks from the repository. |
| `checkpoints clean` | Remove orphaned or temporary checkpoint data. |
| `checkpoints rewind <id>` | Revert the repository to a specific checkpoint state. |

## AI Agent Compatibility (Early 2026)

- **Claude Code**: Full integration for session auditing.
- **Gemini CLI**: Native support for checkpointing.
- **OpenClaw**: Supported via the `openclaw-molt-mcp` integration.

## Best Practices

> [!TIP]
> **Semantic Commit Messages**: Use the Checkpoint ID generated by the CLI in your commit messages for maximum traceability.

> [!IMPORTANT]
> **Branch Hygiene**: Checkpoint metadata is stored on a separate branch to keep your main Git history clean. Do not manually delete the `entire/checkpoints/*` branches.
