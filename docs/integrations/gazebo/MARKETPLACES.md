# Gazebo: Free Model Marketplaces

Accessing high-quality, free assets is vital for creating realistic simulation environments. The Sandra ecosystem prioritizes the following free marketplaces.

## ⛽ Gazebo Fuel (Sim Fuel)
The official repository for Gazebo Sim models. It provides easy integration via unique URIs.

- **URL**: [app.gazebosim.org/fuel](https://app.gazebosim.org/fuel)
- **Sandra Usage**: Agentic scripts can pull models directly into the simulation using `fuel.gazebosim.org` resources.
- **Key Providers**: 
  - **Open Robotics**: The primary source for official robot models and common world objects.
  - **MARBLE-Project**: High-density environment assets for subterranean and urban navigation.

## 🏛️ Open Source Model Collections

### 1. **OSRF (Open Source Robotics Foundation) Models**
The legacy set of Gazebo Classic models, still compatible with modern Sim via the bridging layer.
- **Resource**: Standard `models.gazebosim.org` distribution.

### 2. **Community Robotics Repos**
- **Unitree Robotics (Unitree-Sim-Models)**: Official free models for the **Go2**, **B2**, and **R1** humanoid. 
- **AgileX Robotics (Scout-Sim)**: Verified physics models for the **Scout Mini** and **Scout 2.0**.

## 🏗️ 3D Model Repos (Conversion Required)
High-fidelity assets requiring conversion via **Blender-MCP**.
- **Poly Haven**: SOTA texturing and environment HDRIs (All CC0).
- **Sketchfab (Free/CC License)**: For unique architectural and botanical assets.
