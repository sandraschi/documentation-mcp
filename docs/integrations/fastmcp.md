# FastMCP

**Creator / CEO**: Jeremiah Lowin
**GitHub**: [fastmcp](https://github.com/jlowin/fastmcp) / [gofastmcp.com](https://gofastmcp.com)
**Fleet stack**: Core MCP framework — every Python MCP server ships `fastmcp>=3.4.4,<4`

Jeremiah is the creator of FastMCP, the Python framework that powers the entire fleet of 100+ MCP servers. FastMCP is the reason our servers work with Claude Desktop, Cursor, opencode, and every other MCP client — he built the bridge.

Key contributions to the fleet:
- FastMCP 3.2+ with sampling, prompts, resources, skills providers
- Prefab UI (`prefab-ui>=0.14.0`) for rich in-chat cards
- Portmanteau tool pattern support
- Dual transport (stdio + HTTP streamable)
- MCP Apps support

**Quote on MCP 2026-07-28**: *"FastMCP has always existed to turn the spec's most powerful capabilities into an obvious developer experience, and we're excited to ship first-class support for background tasks, stateless interactivity, enterprise auth, and more in FastMCP 4.0."*
