# Inkscape: The Vector & Schematic Authority

Inkscape is the primary vector graphics engine for the Sandra ecosystem. It is used for designing technical schematics, SVG assets for the webapp, and precise 2D blueprints for robotics fabrication.

## 🏛️ Role in the Sandra Ecosystem

- **Schematic Design**: Creating high-precision 2D diagrams of the fleet's hardware and network topology.
- **Web UI Assets**: Authoring SVG icons and illustrations for **mcp-central-docs**.
- **Automation Target**: Headless SVG manipulation and bitmap export via the **Command Line interface**.
