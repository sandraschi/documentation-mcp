# Stable Audio: Environmental Soundscapes

**Category**: Audio FX / Ambient Generation  
**Status**: Stability AI Core (v2.0)  
**Primary Strength**: Long-form non-musical textures

## Overview
**Stable Audio** (by Stability AI) uses a latent diffusion architecture similar to Stable Diffusion, but optimized for the audio domain. While often used for music, it is the fleet's primary tool for generating complex, multi-layered environmental soundscapes.

## 🛠️ Key Features
- **High Complexity**: Able to simulate dozens of simultaneous sound sources (e.g., "a jungle at night with crickets, distant waterfalls, and occasional bird calls").
- **Long Duration**: Can generate consistent audio for up to 3 minutes, ideal for background "room tone" or ambient textures.
- **Stereo Width**: Exceptional spatial imaging, providing a wide "cinematic" stage.

## 📝 Usage Patterns

| Pattern | Description |
| :--- | :--- |
| **Room Tone** | The subtle, unique background noise of a specific space (computer hum, air conditioning). |
| **Crowd Wallah** | The indistinct chatter of a group or marketplace. |
| **Evolving Textures** | Sounds that subtly change over time, preventing the "loop exhaustion" common in static samples. |

---
> [!TIP]
> When prompting for soundscapes, use "environment-first" language: *"Interior of a derelict space station, low-frequency hum, occasional rattling metal, dripping water, very reverb-heavy."*
