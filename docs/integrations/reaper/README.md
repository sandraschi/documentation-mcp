# Reaper: Professional Audio & Studio Orchestration

REAPER (Rapid Environment for Audio Production, Engineering, and Recording) is the primary digital audio workstation (DAW) in the **Sandra** ecosystem. It is used for audio post-production, sound design for the robotics fleet, and real-time studio orchestration.

## 🏛️ Role in the Sandra Ecosystem

- **Audio Post-Production**: Final mastering for documentary videos and fleet announcements.
- **Sound Design**: Creating auditory feedback signatures for the **Unitree** and **Scout** robots.
- **Real-Time Orchestration**: Managing multi-channel audio routing via the **OSC** protocol and the **Reaper Python API**.
