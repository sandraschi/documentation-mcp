# Homarr: Fleet Dashboard Orchestration

Homarr provides a high-performance, customizable dashboard for the entire fleet. It serves as the primary visual landing page for the **Sandra** ecosystem, aggregating links, status indicators, and real-time metrics from the **58 services** in the grid.

## 🚀 Deployment & Integration

### Core Infrastructure
- **Framework**: Docker-based deployment.
- **Port**: `7575` (Default).
- **Function**: Centralized UI for fleet service discovery and shortcut management.

## 🖥️ Dashboard Features
- **Service Shortcuts**: One-click access to all active MCP webapps (Plex, Immich, Mcp Central Docs, etc.).
- **Status Monitoring**: Integration with **System Admin MCP** to display real-time node health.
- **Search Integration**: Unified search across the fleet's documentation and external tools.

## 🛠️ Advanced SOTA Workflows

### The "SOTA Launchpad"
Agents use Homarr to provide a "Home Base" for the user:
1. **Automation**: `universal_actuator` triggers a fleet-wide sync.
2. **Notification**: Agent updates the Homarr status widget to show "Sync Complete".
3. **Presence**: User monitors the entire **24-core Ryzen** grid from a single pane of glass.
