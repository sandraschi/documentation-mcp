# FastMCP 4.0.5 GA Assessment — Sampling Removed, Fleet Stays on 3.4

Date: 2026-09-20
Status: GA stable (4.0.0 Four Real + 4.0.1-4.0.5 patches)
Supersedes beta note: fastmcp-4-assessment.md (2026-08-01, 4.0.0b1)
Sources: https://gofastmcp.com/getting-started/whats-new, https://gofastmcp.com/getting-started/upgrading/from-fastmcp-3, https://gofastmcp.com/servers/sampling, https://github.com/PrefectHQ/fastmcp/releases

## 0. TL;DR

- 4.0.5 is real and stable. Nothing in 4.0.0-4.0.5 justifies a fleet upgrade now.
- YES — `ctx.sample()`, `ctx.sample_step()`, `ctx.list_roots()` are removed on ALL protocol eras. `AttributeError` at upgrade, not at runtime.
- `ctx.elicit()` is era-gated: works handshake-era, raises on modern 2026-07-28 (which `Client(mode=auto)` negotiates by default).
- Fleet pin stays: `fastmcp>=3.4.7,<4`. 3.4.7 got a security backport 2026-08-10, 3.x is still maintained.
- Sequence unchanged from beta assessment: fleet-llm first (kill ctx.sample dependency), FastMCP 4 second. Canary learnbot-mcp when ready.

## 1. Release map (what 4.0.5 actually is)

- 4.0.0 Four Real: SDK v2 + spec 2026-07-28 sessionless, dual-era negotiation, guard tools, TasksExtension, extensions API, completions, identity assertion SEP-990 beta, gateway headers, cache hints. 5 betas / 5 wks / 23 contributors / 80+ PRs.
- 4.0.1 Come Back Any Time: ClientGroup context reentrancy.
- 4.0.2 Root Access: `from fastmcp import ClientGroup`.
- 4.0.3 Once Is Enough: mixed-era startup perf, unconstrained-sequence image dup, task timing serialization, Monty callback cleanup.
- 4.0.4 Here Be No Dragons: OpenAPI multipart string arrays, whole-body vs HTTP param collision, dict/raw/JSON-scalar bodies, OAuthProxy ID-JAG guard (#5119), non-positive expiry reject, pagination cursors, local-provider get_tasks transforms.
- 4.0.5 No Country for Loose Ints: restores `Field(strict=True)` / StrictInt / strict model config in lax mode (#5141) + ID-JAG regression test (#5146). No features.

Nothing fleet-relevant unless you run OpenAPI proxy or strict validation.

## 2. Sampling — the shite part, precisely

Protocol cause: 2026-07-28 removed server-initiated requests (SEP-2322) because stateless has no live back-channel; sampling separately deprecated (SEP-2577, docs correction #4988 attributes to SEP-2322/2575). Not SEP-1572.

| Surface | 3.4 | 4.0.5 |
|---|---|---|
| `ctx.sample` / `sample_step` | works | removed, AttributeError all eras |
| `ctx.list_roots` | works | removed, take paths as args or guard pattern |
| `FastMCP(sampling_handler=)` | works | TypeError naming migration |
| `Client(sampling_handler=)`, `Client(roots=)` | works | works, serves both push (legacy) and guard (modern) |
| `ctx.elicit` | works | handshake-only, ToolError on modern |
| `ctx.info` logging | works | works all eras (notification, not request) |

Replacements per /servers/sampling:
1. Own the key: `anthropic.AsyncAnthropic()` at module scope, generate inside tool. Same for every client, no round-trip, testable standalone. Preferred.
2. Borrow caller model: return `InputRequiredResult(result_type=input_required, input_requests={key: CreateMessageRequest(...)})`, re-run from top, read `ctx.input_responses[key]` as `CreateMessageResult`. `fastmcp.Client` drives loop via existing sampling_handler. One full request/response per generation — expensive for chains. Can mix sampling+elicitation+roots keys in one map. Needs 2026-07-28 connection.
3. Roots: guard pattern or plain tool args (simpler).

Official line: if borrowing caller model IS the server (no own key, bill was never yours), stay on 3.x.

Fleet impact: agentic_file_workflow, discord_agentic_workflow, vm_agentic_workflow all depend on ctx.sample. Migration = rewrite to guard pattern + per-LLM-call round-trip. Do not migrate before fleet-llm.

## 3. What 4 improves (with sampling out of picture)

- Dual-era serving: one deployment negotiates best mutual version per connection. Modern = self-contained requests, any replica behind plain LB, no affinity. `Client(url)` mode=auto probes modern, falls back.
- Gateway headers: Mcp-Method / Mcp-Name + opted-in args as HTTP headers (SEP-2243). Route without JSON parse.
- ClientGroup: one managed client per server, collision-checked {server}_{tool}, per-member era negotiation, no proxy middle.
- Guard interactive tools: return input description, complete normally, client fulfils, re-call with answers on ctx.input_responses. REQUEST_STATE_KEY shared across replicas (32+ bytes secret).
- UserSession / SessionId + session_state_store: server-side state bound to authed user, survives fresh connections. In-memory default, Redis/Valkey for shared/durable.
- Background tasks via io.modelcontextprotocol/tasks extension (SEP-2663): `fastmcp[tasks]` + `mcp.add_extension(TasksExtension())` or RuntimeError at startup. `@mcp.tool(task=True)` tools-only (resources/prompts task= now TypeError). Client `call_tool` polls transparently, `call_tool_task` for handle. Docket engine. Legacy clients run synchronously, never tasked.
- Extensions: `add_extension()` advertise caps, add methods, intercept tools/call, own lifespan. Tasks is the reference impl.
- @mcp.completion: prompt/resource-template arg completion with prior args visible.
- Enterprise: IdentityAssertion ID-JAG SEP-990 beta, require_roles(extract=), scope step-up challenges SEP-2350, ClientCredentialsOAuthProvider M2M, DCR application_type SEP-837.
- Prod: cache_ttl/cache_scope + KeyValueResponseCacheStore, path-traversal/absolute/null-byte screen on templated resources (exempt via ResourceSecurity), InsufficientScopeError naming scopes, DI Depends(factory) + CallArgument binding, ClientGroup, snake_case types (wire stays camelCase, mcp_camelcase_compat shim warns, set False in CI to find all reads).
- Correctness from beta: OAuth consent/issuer/JWT, proxy cookie/connection-header strip, encrypted task snapshots, serialized event-store, response cache empty/error/versioned handling, py3.14 compat.

## 4. Migration costs (mechanical but wide)

Env: pydantic>=2.12, Starlette>=1.0.1 (FastAPI>=0.133.0 first admitting Starlette 1.x). Resolver failure, not bump, if pinned below.

Imports moved (ModuleNotFoundError): server.proxy -> server.providers.proxy, server.openapi/FastMCPOpenAPI -> OpenAPIProvider, experimental.server.openapi -> server.providers.openapi, experimental.utilities.openapi -> utilities.openapi, experimental.sampling.handlers OpenAISamplingHandler -> client.sampling.handlers.openai, server.apps/app -> apps/fastmcpapp, tools.tool/resource.resource/prompts.prompt component shims -> tools/resources/prompts + function_* submodules, server.auth.authorization -> server.auth / utilities.authorization, SkillsProvider -> SkillsDirectoryProvider, server.tasks TaskConfig -> utilities.tasks, CurrentDocket/CurrentWorker -> fastmcp_tasks.dependencies, Cachable* -> Cacheable* (no alias), PromptToolMiddleware/ResourceToolMiddleware -> PromptsAsTools/ResourcesAsTools transforms.

Methods: as_proxy -> create_proxy(target) (positional, not backend= kw), import_server -> mount (NOT equivalent: snapshot no-lifespan/no-middleware vs live + lifespan/middleware), mount(prefix=) -> namespace=, mount(as_proxy=True) -> mount(create_proxy(child)), add/remove_tool_transformation -> add_transform/disable, remove_tool -> local_provider.remove_tool (KeyError not NotFoundError), tool serializer=/exclude_args= removed (return ToolResult / Depends(factory)), StreamableHttpTransport(sse_read_timeout=) removed (Client timeout=), decorator_mode removed, ctx.elicit requires response_type (bool for confirm).

Errors: McpError(ErrorData(...)) positional -> McpError(code=, message=). Catching unchanged.

HTTP: httpx -> httpx2 exclusively. `except httpx.` still imports (transitive via Anthropic/OpenAI/Google SDKs) but never matches — silent dead code. Grep and swap. Custom httpx_client_factory / httpx.Auth -> httpx2. from_openapi client duck-typed temporarily with warning. TLS now OS truststore (truststore, SSL_CERT_FILE/DIR) not certifi. Loggers httpx/httpcore.* -> httpx2/httpcore2.*.

Behavior: elicit era-gate (most likely runtime bite), Client(str .py) deprecated -> Path/StdioTransport (removal v5), middleware on_message/on_request/on_notification now sees every message incl. notifications/cancelled/initialized/progress + unroutable/validation-failed (guard message type; op hooks unaffected), templated .. / absolute exempt only via security=None/exempt_params, -32002 -> -32602 resource-not-found, issuer_url != base_url forces one-time full re-auth (refresh won't cross), ping/set_logging_level/on_initialize/set_state-across-calls all era-dependent (see table in upgrade guide), no server-side protocol restrict — server depending on handshake depends on callers opting mode=legacy.

Checklist executable: tests/test_upgrade_from_v3.py. Copy-paste auditor prompt in upgrade guide covers all signals.

## 5. Community / risk

- Stars ~27.7k. Beta held under gateways/agent frameworks/prod servers. Maintainer claim most 3.x apps upgrade untouched holds for non-sampling/elicit/state servers.
- No fork/revolt. Samplers annoyed but told to stay; 3.4.7 backport proves 3.x viable.
- httpx2 single-dev fork is the one architectural risk carried over from beta note. OS truststore + logger rename are the sharp edges.
- 4.0.x patch cadence healthy (OpenAPI/OAuth/strict fixes landing fast).

## 6. Fleet decision

Stay on 3.4. Rationale: sampling dependency + elicit gating + dep floors + httpx2 sweep + tasks extra + middleware/state rework, for infra (stateless LB, gateways, ID-JAG) the fleet doesn't use.

Actions:
1. Pin `fastmcp>=3.4.7,<4` fleet-wide.
2. fleet-llm (DeepSeek V4 Flash cloud + Ollama local) to remove ctx.sample blocker.
3. Audit elicits/on_initialize/set_state separately.
4. Canary learnbot-mcp (zero sampling) 2 weeks on 4.x when stable+llm ready, then pilot, then roll.
5. Run upgrade-guide auditor prompt + `FASTMCP_MCP_CAMELCASE_COMPAT=false` in CI during pilot.
