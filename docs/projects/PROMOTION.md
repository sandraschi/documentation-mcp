## Quick rules

1. **README + Glama first** — outward posts only when install path works
2. **Wrappee GitHub** — Discussion > Issue; check anti-AI policies; no rah-rah template
3. **Tone** — show workflow, not “revolution”
4. **One channel at a time** — measure response before cross-posting

See full channel matrix and anti-patterns in [FLEET_PROMOTION.md](../standards/FLEET_PROMOTION.md).
