# My PowerShell Scripts

This repository contains a collection of personal PowerShell scripts.

## Folders

*   **useful_scripts**: A collection of utility scripts for various tasks.

- **Desktop-Organize-Inator.ps1** — Instantly tidy your desktop icons into neat grids.
- **Taskbar-AutoHide-Fixinator.ps1** — Fixes the stubborn Windows taskbar auto-hide bug.
- **Network-Adapter-Resetinator.ps1** — Resets your network adapters in one click.
- **Temp-File-Annihilator.ps1** — Obliterates temp files for a cleaner, faster system.
- **Font-Cache-Rebuildinator.ps1** & **IconCache-Rebuildinator.ps1** — Rebuilds font/icon caches to fix weird glitches.
- **System-Tray-Declutterinator.ps1** — Cleans up your system tray for a zen workspace.
- **Window-Position-Restorizer.ps1** — Restores all your windows to their favorite spots.
- **Desktop-Critters-Inator-Improved.ps1 / Desktop-Critters-Schmitzinator.ps1 / Animated-Critters-Schmitzinator.ps1** — Spawns animated critters that crawl, hop, and fly across your desktop. Pure desktop joy.
- **Control-Panel.ps1 / WPF** — The ultimate launcher/control center for all your inators and critters.

## Usage

Navigate into the desired script's folder and execute it using PowerShell. Ensure you understand what each script does before running it, especially those in `pranks_scripts`.
