## What It Is

The industrial-grade "Swiss Army Knife" for computational resource management. Filesystem MCP provides a professional portmanteau interface for file operations, Docker orchestration, and Git repository automation.

**Core Mission**: To serve as the trusted execution layer for agentic AI requiring deep access to OS, containers, and source code.

---

## The Three Towers Architecture

### 1. Filesystem Tower (20+ Tools)
- **Basic CRUD**: High-performance reading, writing, and directory management.
- **Deep Analysis**: Duplicate detection (hash-based), large file identification, and diff comparison.
- **Search Engine**: Integrated Grep pattern matching and line-based log extraction.

### 2. Docker Tower (25+ Tools)
- **Container Lifecycle**: Create, start, stop, and execute commands inside containers.
- **Compose Orchestration**: Native support for `docker compose up/down` and service scaling.
- **Network/Volume Mapping**: Professional management of virtual networks and persistent volumes.

### 3. Repository Tower (30+ Tools)
- **Git Lifecycle**: Automated cloning, staging, committing, and branching.
- **History Tools**: Blame, commit history, and diff analysis.
- **Conflict Resolution**: Specialized tools for merging and stash management.
