# mujoco-mcp v0.3.0 — Feature Plan

## Features (in build order)

### F1: Real-Time 3D WebGL Viewer
**Path**: `web_sota/src/pages/Viewer3D.tsx`, `web_sota/src/lib/sim-renderer.ts`, `web_sota/backend/routes/sim_ws.py`
**Dep**: Three.js, WebSocket
**What**: Live 3D rendering of running sims — bodies as Three.js boxes/spheres at joint positions, bone connections. Streams state via WebSocket. OrbitControls for camera.

### F2: Trajectory Recorder + Timeline Playback
**Path**: `src/mujoco_mcp/trajectory.py`, `web_sota/src/pages/TrajectoryViewer.tsx`
**Dep**: F1 (reuses scene renderer)
**What**: Record sim state every N steps → JSON trajectory file. Playback scrubs through recorded frames on the same 3D viewer with a timeline slider.

### F3: Population Runner
**Path**: `src/mujoco_mcp/tools/population.py`
**Dep**: Existing state machine
**What**: Launch N parallel sims with parameter sweeps (gravity, friction, joint damping). Collect results (completion, stability, energy). Show in a table/chart.

### F4: RL Training Playground
**Path**: `src/mujoco_mcp/rl_trainer.py`, `web_sota/src/pages/RLPlayground.tsx`
**Dep**: stable-baselines3, F1
**What**: Define reward via NL, train PPO/SAC in the sim runner, stream reward/logs via WebSocket, show live learning curves. Checkpoint export.

### F5: Gestural MJCF Editor
**Path**: `web_sota/src/pages/ModelEditor.tsx`, `web_sota/src/components/MJCFScene.tsx`
**Dep**: Three.js
**What**: Drag-and-drop bodies, add joints, edit limits. Export as MJCF/URDF. Uses Three.js with raycaster + transform controls.
