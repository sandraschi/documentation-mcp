# civitai-mcp

**Repo:** https://github.com/sandraschi/civitai-mcp  
**Ports:** Backend **11124**, Frontend **11125**  
**Status:** **0.1.0** — complement to [comfyops-mcp](../comfyops-mcp/) / ComfyUI depot

## Role

Civitai marketplace **search + download** into a ComfyUI-shaped models tree (`loras/`, `checkpoints/`, …). Human-approved download outbox; dry-run default. Does **not** run Comfy graphs — that stays in comfyops-mcp.

## Docs

Upstream: `README.md`, `docs/ONBOARDING.md`, `docs/TOOLS.md`.

## Start

Fleet launcher `civitai-mcp-start.bat` or `.\start.bat` in the repo.
