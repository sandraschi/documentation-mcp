# Reversal Targets - Curated Hit List Without Cease-and-Desist Letters

Status: active curation. Last updated: 2026-10-10.

## Thesis

Adobe is the showcase, not the template. A small fleet cannot plan a swarm,
but it can plan a stagnant incumbent that documented its own refusal in a
public tracker. This section ranks Windows software by hittability: math depth
versus user annoyance versus legal exposure. Rule of thumb: hit where the
math is shallow, the users are disgusted, and the owner is dead, distracted,
or structurally unable to sue without embarrassment.

## Standing decisions

1. No Adobe-suite clones from this fleet. ArtCraft owns that war; we bridge to it.
2. Tier 0 first: FOSS and orphaned commercial targets cannot meaningfully C&D,
   and their trackers contain pre-qualified users.
3. Mid-tier only with the shallow-math test passed (reimplementable from papers,
   specs, and pixel-diffing, no decompilation needed).
4. Every target gets behavior specs + differential tests before a line of clone
   code. Specs are legal armor and contributor bait at once.
5. ASCII prose in docs. Max 10 files per commit. Verify by running.

## Flagship example

Mixxx video mixing: years of ignored user requests, disgusted DJs publicly
returning to VirtualDJ/Serato in the tracker. Shallow math (decode, crossfade,
effects routing), documented refusal, pre-gathered users. This is the template
engagement: one refused feature, not the whole app.
