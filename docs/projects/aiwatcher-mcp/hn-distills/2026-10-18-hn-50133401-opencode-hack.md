exposed third-party provider API keys stored in user workspaces. They clarified
that the leak involved 'OpenCode Console', a separate service from the coding
agent, though communication remains unclear. Users are advised to revoke and
replace any exposed keys and review account activity for unauthorized usage.

  clarity on the scope and impact.

  breach and past security practices.

credentials, and whether the company's communication is adequate or
deliberately vague.
