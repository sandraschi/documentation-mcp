## Project Structure Convention

Each project folder contains:
- `STATUS.md` - Current state, features, health
- `ANALYSIS_SNAPSHOT.md` - Optional; written by MetaMCP `publish_analysis_to_mcd` when the project exists under `projects/`
- `STRUCTURE.md` - Directory layout and architecture
- `PATTERNS.md` - Project-specific patterns (if applicable)
- `INTEGRATION.md` - How it integrates with other systems
