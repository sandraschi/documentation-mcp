# MCPB Packaging Tools Changelog

## [1.0.0] - 2025-12-26

### Added
- **setup_all_mcpb.ps1**: Comprehensive MCPB automation script
- **README.md**: Complete documentation and usage guide
- **MCPB directory structure**: Automated setup for new repos
- **Manifest generation**: Proper MCPB v0.2 manifest creation
- **Asset generation**: Icons, prompts, and documentation
- **Source code copying**: Automated source directory setup
- **Build automation**: MCPB CLI integration
- **Package verification**: Content validation and size checking
- **Batch processing**: Multi-repo operations with filtering
- **Error handling**: Comprehensive error reporting
- **Unicode support**: Encoding-safe operations

### Features
- **Three operation modes**: setup, build, verify
- **Repo filtering**: Process specific repos or all repos
- **MCPB standards compliance**: Follows official packaging standards
- **Workspace integration**: Works with all MCP repos in workspace
- **Quality assurance**: Validates packages and structure
- **Documentation**: Extensive inline help and examples

### Technical Details
- **PowerShell 7+** compatible
- **MCPB CLI** integration for official packaging
- **JSON manifest** generation with proper schema
- **PNG icon** creation for package branding
- **Markdown prompts** for Claude Desktop integration
- **Source code detection** with smart pattern matching
- **Package placement** in repo root `/dist` directories
