# Docs MCP – User guide

## Getting started

Ask to search the MCP documentation, e.g.:

- "Find documentation about FastMCP prompts."
- "Search for MCPB packaging standards."
- "Where is the migration guide for FastMCP 3.1?"

For a direct answer:

- "What does the portmanteau pattern mean in MCP?"
- "How do I add a skill in FastMCP 3.1?"

For full file content after a search:

- "Get the full content of standards/MCPB_PACKAGING_STANDARDS.md" (use the path from search results).
