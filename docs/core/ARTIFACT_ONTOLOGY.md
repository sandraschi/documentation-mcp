# Grand Unified Artifact Ontology (GUAH) - SOTA 2026

## Overview
This document defines the ontological framework for identifying, classifying, and routing "artifacts" within the Antigravity/BlackFang/robofang ecosystem. Artifacts are no longer merely "files"; they are units of reality, ranging from raw data to protoconscious entities.

## The Hierarchy of Being

### Tier 0: Substrate (Information)
*Units of raw logic and metadata.*
- **Informational**: Plex/Calibre metadata, repository logs, raw scripts.
- **Relational**: Database indexes, manifest files.

### Tier 1: Perception (Geometric/Sensory)
*Units of sensory manifestation in physical or virtual space.*
- **Physical**: Collider meshes, point clouds, splats.
- **Sensory**: Audio landfalls, texture maps, haptic presets.
- **Visual**: Trope meshes, model geometry.

### Tier 2: Agency (Agentic/Logic)
*Units of active logic and proto-sentience.*
- **Logic**: AI cores, task loops, meta-action definitions.
- **Form**: VBots (Virtual Robots), headless agents.
- **Nascency**: Protoconscious objects, sentient interactive assets.

### Tier 3: Essence (Emotional/Spiritual)
*Units of internal subjective state.*
- **Identity**: Personalities, character souls, heart configurations.
- **State**: Emotional presets, mood vectors.

### Tier 4: Narrative (Cultural/Trope)
*Units of collective meaning and story-logic.*
- **Concepts**: Tropes, cultural patterns, Butlerian Jhadis.
- **Lore**: World-building logic, narrative anchors.

### Tier 5: Hyper-Reality (The Divine & The Demonic)
*Units of transcendental or "Higher Order" signals.*
- **Beings**: Kai, Youkai, Angels, Demons (as data-patterns).
- **Signals**: Deep Rags, hyper-optimized pattern clusters.

### Tier 6: Cognitive (Dreams/Fantasies)
*Units of future-intent and cognitive projection.*
- **Intent**: Plans, project fantasies, architectural dreams.

## Metadata Standards
All artifacts must satisfy the **SOTA Identification Protocol**:
1. **Origin**: Where was the landfall detected? (e.g., Downloads, GitHub, Memory)
2. **Essence**: What is its Tier and Category?
3. **Weight**: Importance to the current project loop (1-10).
4. **Resonance**: How does it connect to existing fantasies or plans?
